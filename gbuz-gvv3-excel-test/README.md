# ГБУЗ ГВВ № 3 ДЗМ Excel Test Assignment

## Описание проекта

Проект выполнен в рамках тестового задания по Excel для ГБУЗ ГВВ № 3 ДЗМ.

Цель работы - решить набор практических задач в Excel: найти уникальные значения, рассчитать частоты, выполнить поиск по условиям, обработать дубликаты, построить диаграмму и преобразовать плоскую таблицу медицинских показателей в нормализованный табличный формат.

Проект демонстрирует уверенную работу с Excel-формулами, динамическими массивами, поисковыми функциями, агрегацией данных и подготовкой таблицы к дальнейшему анализу.

## Что было сделано

### Sheet_2

Решены задачи на работу с городами и улицами:

- найдены уникальные города и улицы с листа `Sheet_1`;
- рассчитано количество повторений каждого уникального города и каждой уникальной улицы;
- рассчитано общее количество уникальных городов и улиц;
- использованы динамические массивы и формулы вида `UNIQUE`, `COUNTIF`, `ROWS`.

### Sheet_3

Решены задачи на поиск и расчёт по найденным значениям:

- для заданных городов найдена первая улица по списку;
- найдено количество жителей для соответствующих строк;
- рассчитано количество повторов найденных улиц по данным `Sheet_2`;
- рассчитан итог по задаче №3*;
- построена столбчатая диаграмма по значениям улиц, жителей и количества повторов.

По задаче №3* в сопроводительном письме отдельно зафиксирована интерпретация формулировки: итог рассчитан как произведение общего количества жителей на среднее количество повторений улиц.

### Sheet_4

Решены задачи на очистку и поиск по массиву данных:

- удалены дубликаты городов и улиц;
- рассчитаны минимум, среднее и максимум по количеству жителей;
- найдены город и улица по рассчитанным значениям;
- для среднего значения использован режим приблизительного совпадения;
- рассчитана сумма количества жителей по заданным условиям через `SUMIFS`.

По задаче №3 в сопроводительном письме отдельно указано, что для приблизительного совпадения выбран поиск ближайшего меньшего значения как наиболее типичный вариант в Excel.

### Sheet_5

Решена задача по преобразованию плоской таблицы:

- исходная широкая таблица приведена к структуре, аналогичной примеру на `Sheet_6`;
- результат вынесен на отдельный лист `Решение для Sheet_5`;
- сформирована нормализованная таблица с полями `Год`, `Месяц`, `План/факт`, `ID`, `Profil`, `Кол-во`.

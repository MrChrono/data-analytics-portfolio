# Data Management 365 - Excel Test Assignment

Тестовое задание для компании **Data Management 365** на работу с табличными данными в Microsoft Excel и документирование решения.

## Задачи

1. Рассчитать средний размер файлов типа `sound`.
2. Определить самую раннюю дату изменения файла с приоритетом `low`, сопоставив данные из двух таблиц.
3. Найти записи из Table 1, отсутствующие в Table 2, добавить их и присвоить `priority` по размеру файла и `checked = No`.
4. Подготовить отчёт в Microsoft Word с описанием решения и пошаговой инструкцией к заданию №3 на русском и английском языках, затем экспортировать его в PDF.

## Подход

Для сопоставления записей использовалась комбинация `file + type`, поскольку имя файла само по себе не является уникальным. В решении применены вспомогательные диапазоны и формулы Excel, позволяющие явно проследить логику вычислений.

Основные функции:

- `AVERAGEIF` - расчёт среднего размера файлов типа `sound`;
- `XLOOKUP` - перенос `last modification date` из Table 1 в вспомогательный столбец Table 2;
- `MINIFS` - поиск минимальной даты среди файлов с `priority = low`;
- `COUNTIFS` - проверка наличия комбинации `file + type` в Table 2;
- `FILTER` - вывод отсутствующих записей во вспомогательную таблицу;
- `IF` - присвоение приоритета по размеру файла.

## Результаты

- Средний размер файлов типа `sound`: **23,53 MB**.
- Самая ранняя дата изменения файла с приоритетом `low`: **19.05.2018**.
- Найдено **5** отсутствующих записей: `Protection / picture`, `Racing / sound`, `Playground / picture`, `Mint / text`, `birds / sound`.
- Недостающие записи добавлены в Table 2, для них рассчитан `priority` и установлено `checked = No`.
- Подготовлен двуязычный отчёт с пошаговым описанием решения задания №3.
